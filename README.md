# 理财知识图谱（小白词典式）

给**理财小白**用的术语图谱：**217 个词**，每个词一份拆成五栏的解释，一张能点着走的图。

**打开方式：双击 `graph.html`** —— 单文件、不依赖网络、不需要任何环境。
打开时按 1:1 落在「基金」上（首屏约 5 个带字可读的词），点图上任意一个词，右栏出解释；
解释底下的关系词是**可点的 chip**，能顺着图一路走。右上「看全图」缩成点阵概览。

## 规模

| 项 | 数 |
|---|---|
| 词条 | 217 |
| 解释 | 217 条（一句话 / 例子 / 误区 / 辨析 / 提醒）|
| 分类节点 | 72（只标"这是什么类"，不写长解释）|
| 边 | 625（属于 / 对比 / 前提）|

图的骨架是**三层节点模型**：词条（写完整解释）+ 分类节点（从「属于」列推导出来的上位概念）
+ 断边（「对比」「前提」指到这两者之外 ⇒ 一律是 bug，脚本负责喊出来）。

## 管线：四段单向投影，`词表-v1.md` + `解释.md` 是唯一真源

```
词表-v1.md  +  解释.md
      │
      ├─ parse_terms.py ──► terms.json          （词表五项检查）
      │
      ├─ build_graph.py ──► graph_data.json     （两层一致性 + 布局 + 自检）
      │        └─ 读 graph_template.html 内联数据 ──► graph.html
      │
      └─ verify_page.py                            （语法 + 面板 + 点开收起 + 真浏览器）
```

**改词表只改 md，然后重跑脚本。** 在 md 里删一个词、而别的词还用对比/前提指着它，
图上就多一条断边，`parse_terms.py` 会喊出来 —— 这就是"单向投影"的意思：md 是源，其余全是产物。

## 验证

```bash
python3 verify_page.py              # 全套，约 11 秒
python3 verify_page.py --selftest   # 故障注入自测，约 14 秒
```

**退出码非零即失败**，可以直接接在 `&&` 后面。

`--selftest` 是**证明这套尺子不是空话**的那条：它往页面里注入 **19 条故障**
（数据/页面层 15 条 + 真浏览器渲染层 4 条），**每条都必须让判据变红** ——
红不了就说明那条断言是空话。含真 firefox 跑一遍页面再读屏幕上的色块，
覆盖桩看不见的那一层（CSS 优先级、栅格行高、viewBox 缩放、窄屏 position:fixed 面板）。

## 数据层（给下一步的智能体用）

`graph_data.json` 里每个词条带 `f`（五栏字段）、`vs`（辨析对象）、`deg`、`root`（无前提 = 教学起点）、
`cat`/`catName`/`fam`；分类节点带 `members`/`refs`；`links` 带关系名。
**这些字段就是给智能体走图用的**，无需再从正文里解析自然语言。

## 几条设计取舍（不是随手写的）

- **布局在构建期用 numpy 烘焙好，不在浏览器里现跑** —— 换来确定性（同种子同图）、
  可验证（布局是纯数字，判据能直接算）、首屏即静止（没有节点乱飞的动画）。
  自检三条：包围盒宽高比 1.02 / 最近邻最小 150.6（无重叠）/ 同族平均 1153 < 异族平均 2220（成簇）。
- **解释必须拆成字段，不能写散文** —— 后面要接智能体做对话式，散文到时整份要重做。
- **面板用侧滑抽屉，不用 modal** —— 面板里的关系是**可点的 chip**，modal 会把这条路堵死。
- **14 个二级类塌成 6 个色族** —— 14 种颜色人眼分不开，6 种可以；字母仍逐个标在节点和面板上，
  颜色只负责"一眼看出这是哪一大片"。
- **「对比」边不对称是对的，不是 bug** —— 它是最邻近关系：混合基金的最近混淆对象是股票基金和债券基金，
  而股票基金的最近邻是债券基金。**最近邻天然不对称**。

## 已知取舍

- 对比/前提是**人工标注**的教学关系，不是从语料里算出来的。
- 「属于」列推导出的 72 个分类节点只有一句说明，不展开成长解释（它们不是词条）。
- `解释-v1.md` 是早期 19 条的文风试点，**已被 `解释.md` 取代**，未入库。
